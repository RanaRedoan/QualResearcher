# QualResearcher: বাংলা ইন্টারভিউ ট্রান্সক্রিপশন (লোকাল PC সংস্করণ)

বাংলা অডিও (IDI, KII, FGD, case study) থেকে এই টুল বানায়:

- **বাংলা verbatim প্রতিলিপি**
- **ইংরেজি অনুবাদ (ঐচ্ছিক)**: শুধু বাংলা নিলে সময় আর AI-এর খরচ দুটোই প্রায় অর্ধেক
- **Speaker label আর timestamp**, সাথে [হাসি], [কান্না], [দীর্ঘ নীরবতা]-এর মতো cue
- **অস্পষ্ট অংশ চিহ্নিত** (হলুদ highlight), যাতে রিভিউয়ার শুধু সেগুলোই মিলিয়ে দেখেন
- **Word ফাইল:** সাদামাটা, পেশাদার লেআউট। timestamp ছাড়া বা timestamp সহ; অনুবাদ থাকলে পাশাপাশি টেবিলও।
- **লাইভ ট্রান্সক্রিপ্ট:** লেখা তৈরি হতে হতেই পেজে দেখা যায়। মাঝপথে থেমে গেলে কোন মিনিটে থেমেছে দেখায়, আর যতটুকু হয়েছে তার Word ফাইল নামানো যায়।

সবকিছু আপনার নিজের কম্পিউটারে চলে। অডিও শুধু ট্রান্সক্রিপশনের সময় Google Gemini API-তে যায়।

## ১. একবারের সেটআপ (Windows)

### ক) Python
আগে থেকে না থাকলে https://www.python.org/downloads/ থেকে Python 3.12 বা নতুন ভার্সন ইনস্টল করুন। ইনস্টলের সময় **"Add python.exe to PATH"** টিক দিতে ভুলবেন না।

### খ) ffmpeg (অডিও কাটার টুল)
PowerShell খুলে চালান:
```
winget install Gyan.FFmpeg
```
তারপর PowerShell বন্ধ করে আবার খুলুন। `ffmpeg -version` লিখলে ভার্সন দেখালে বুঝবেন ঠিক আছে।

### গ) Gemini API key
1. https://aistudio.google.com এ যান। লগইন করুন আপনার ব্যক্তিগত Google অ্যাকাউন্ট দিয়ে।
2. বাম পাশে **Get API key** → **Create API key** চাপুন।
3. **Copy key** চেপে key-টা কপি করুন (`AQ.` বা `AIza` দিয়ে শুরু হয়)।
4. ⚠️ **আসল participant-দের অডিও পাঠানোর আগে billing চালু করুন** (AI Studio → *Billing* / *Set up billing*)। Google-এর শর্ত অনুযায়ী free tier-এ পাঠানো ডেটা তারা প্রোডাক্ট উন্নত করতে ব্যবহার করে, এমনকি মানুষ রিভিউয়াররাও পড়তে পারে। paid tier-এ এর কোনোটাই হয় না। ethics/IRB-এর দিক থেকে এটা গুরুত্বপূর্ণ। বিস্তারিত: https://ai.google.dev/gemini-api/terms
5. key কখনো কোডে, GitHub-এ বা কারো সাথে শেয়ার করবেন না। শুধু `.env` ফাইলে থাকবে।

## ২. চালানো

1. এই ফোল্ডারে **`start.bat`** ডাবল-ক্লিক করুন।
2. প্রথমবার নিজে থেকেই প্যাকেজ ইনস্টল হবে (কয়েক মিনিট লাগে)। তারপর Notepad-এ `.env` ফাইল খুলবে। `GEMINI_API_KEY=` এর পরে key বসিয়ে **Save** করে Notepad বন্ধ করুন।
3. browser-এ `http://127.0.0.1:8000` খুলবে। **Create account** দিয়ে একটা অ্যাকাউন্ট বানান। প্রথম অ্যাকাউন্টটাই admin হবে।
4. **New upload** → ফাইল টেনে আনুন → **Output**-এ "বাংলা ট্রান্সক্রিপ্ট" অথবা "বাংলা + English" বাছুন → শিরোনাম দিন → consent বক্সে টিক দিয়ে **Start transcription**।
5. শেষ হলে **Word** (টাইমস্ট্যাম্প ছাড়া, পরিষ্কার) বা **Word with timestamps** ডাউনলোড করুন। শুধু বাংলা করে থাকলে পরে ট্রান্সক্রিপ্টের পেজ থেকে **+ Add English translation** চাপলেই ইংরেজি যোগ হবে।

> কাজ চলার সময় কালো `start.bat` উইন্ডোটা খোলা রাখবেন। মাঝপথে বন্ধ হয়ে গেলে ওই job-এ **Start again** বাটন আসবে।

### অনেকগুলো ফাইল একসাথে (পুরো ফোল্ডার)
**`transcribe_folder.bat`** ডাবল-ক্লিক করুন। ফোল্ডারটা উইন্ডোতে টেনে আনুন, ইন্টারভিউয়ের ধরন দিন, আর ইংরেজি অনুবাদ লাগবে কি না বলুন (Enter চাপলে শুধু বাংলা)। Google ব্যস্ত থাকলে এটা নিজে অপেক্ষা করে আবার চালায়। প্রতিটা অডিওর Word ফাইল ওই ফোল্ডারের ভেতরে `transcripts` সাব-ফোল্ডারে জমা হবে। কোনোটা মাঝপথে থেমে গেলে যতটুকু হয়েছে সেটা `নাম-partial.docx` হিসেবে সেভ হয়, আর পরেরবার চালালে সেখান থেকেই বাকিটা করে। যেগুলো আগে হয়ে গেছে সেগুলো বাদ যায়। আপনার আসল অডিও ফাইলে কোনো পরিবর্তন হয় না।

কমান্ড লাইন থেকে চালাতে চাইলে:
```
%LOCALAPPDATA%\Kothon\venv\Scripts\activate
python manage.py transcribe_folder "D:\Interviews\Round1" --type FGD --speakers 8 --context "মাইক্রোফাইন্যান্স, কুড়িগ্রাম, BRAC"
```

## ৩. ফ্রি প্ল্যানে লম্বা অডিও (১ ঘণ্টা+) চালানোর নিয়ম

ফ্রি প্ল্যানে Google মাঝে মাঝে "busy" (503) বা "limit" (429) দেখায়। QualResearcher এটা নিজেই সামলায়:

- অডিও ২০ মিনিটের টুকরোয় ভাগ হয় (`CHUNK_SECONDS=1200`), তাই ১ ঘণ্টার অডিওতে মাত্র ৩টা request লাগে। দিনের ফ্রি request সীমাই সাধারণত আগে শেষ হয়, তাই টুকরো বড় রাখলে একই সীমায় বেশি অডিও হয়। প্রতিটা টুকরোর লেখা আসতে আসতেই সেভ হয়।
- Google ব্যস্ত থাকলে প্রথমে কয়েক মিনিট অপেক্ষা করে আবার চেষ্টা করে, তারপর বিকল্প মডেল (`gemini-3.6-flash`) দিয়ে।
- তাতেও না হলে job বাতিল হয় না। স্ট্যাটাসে লেখা থাকে "trying again automatically at HH:MM", আর ১০ মিনিট পরপর (মোট ৬ বার পর্যন্ত) নিজে থেকে বাকি টুকরোগুলো চালায়। আগের টুকরো আবার পাঠায় না।
- দিনের ফ্রি সীমা শেষ হলে পরিষ্কার মেসেজ দেখাবে। পরদিন **Try again** চাপলে যেখানে থেমেছিল সেখান থেকে চলবে।
- শুধু বাংলা বাছলে অনুবাদের অনুরোধগুলো পাঠানোই হয় না, তাই সীমায় পৌঁছানোর সম্ভাবনা অনেক কমে।
- মডেলকে কম "thinking" করতে বলা হয় (`GEMINI_THINKING_LEVEL=low`), এতে উত্তর দ্রুত আসে আর টোকেন কম লাগে।

- কাজ চলার সময় ট্রান্সক্রিপ্টের পেজে **Live transcript**-এ লেখা আসতে থাকে, আর দেখায় অডিওর কত মিনিট পর্যন্ত হয়েছে।
- কোনো কারণে থেমে গেলে পেজে লেখা থাকে **"Stopped at 23:40 of 58:07"**। পাশে দুটো বাটন: **Word — what's done so far** (যতটুকু হয়েছে তার Word ফাইল, উপরে "Incomplete" লেখা থাকে) আর **Continue from 23:40**।

কালো `start.bat` উইন্ডোটা খোলা রাখবেন। বন্ধ হয়ে গেলেও কিছু হারায় না, পরে **Continue** চাপলেই হবে।

## ৪. ভালো ফলাফলের টিপস

- **Context for the AI** ঘরে গবেষণার বিষয়, জায়গা, প্রতিষ্ঠান বা প্রকল্পের নাম লিখুন। নামের বানান অনেক বেশি ঠিক হয়।
- FGD-তে আনুমানিক কতজন বক্তা, সেটা দিন।
- অডিও যত পরিষ্কার, ফল তত ভালো। একসাথে কথা বলা আর পেছনের আওয়াজ থাকলে ভুল বাড়ে। সেই অংশগুলো `[অস্পষ্ট]` দিয়ে চিহ্নিত থাকে।
- বাংলার ভেতরের ইংরেজি শব্দ (loan, process) ডিফল্টভাবে বাংলা হরফে আসে (লোন, প্রসেস)। ইংরেজি হরফে চাইলে `.env`-এ `ENGLISH_WORDS_SCRIPT=latin` দিন।
- **AI-এর লেখা সবসময় প্রথম খসড়া।** বিশ্লেষণের আগে একজন RA দিয়ে অডিওর সাথে মিলিয়ে নিন।

### কোন মডেল?
ডিফল্ট `gemini-3.8-flash`, দ্রুত আর সস্তা। আরও নির্ভুল দরকার হলে `.env`-এ `GEMINI_TRANSCRIBE_MODEL=gemini-4-argon` দিয়ে একটা নমুনা ইন্টারভিউতে দুটো মিলিয়ে দেখুন। বর্তমান মডেলের তালিকা: https://ai.google.dev/gemini-api/docs/models

### খরচ
Gemini অডিওর প্রতি সেকেন্ডে ৩২ টোকেন গোনে, অর্থাৎ ১ ঘণ্টা অডিও ≈ ১,১৫,২০০ input টোকেন। সাথে ট্রান্সক্রিপ্ট আর অনুবাদের output টোকেন যোগ হয়। বর্তমান রেট: https://ai.google.dev/gemini-api/docs/pricing। প্রথমে ছোট একটা ফাইল চালিয়ে AI Studio-র usage পেজে খরচ দেখে নিন।

## ৫. ডেটা কোথায় থাকে

প্রজেক্ট ফোল্ডার Google Drive-এর ভেতরে থাকতে পারে। তাই অডিও, ডাটাবেস আর Python প্যাকেজ রাখা হয় **ফোল্ডারের বাইরে, শুধু এই কম্পিউটারে** (`%LOCALAPPDATA%\Kothon`)। এতে participant-দের অডিও Drive-এ sync হয় না, আর sync চলার সময় ডাটাবেস নষ্ট হওয়ার ঝুঁকিও থাকে না।

| জিনিস | কোথায় | কতদিন |
|---|---|---|
| কোড, `.env` | এই ফোল্ডার (Drive-এ থাকলে sync হবে) | — |
| আপলোড করা অডিও | `%LOCALAPPDATA%\Kothon\private_media` | আপলোডের সময় বাছা ১–৩ দিন। ড্যাশবোর্ড খুললে মেয়াদ শেষ হওয়া অডিও মুছে যায় |
| ট্রান্সক্রিপ্ট | `%LOCALAPPDATA%\Kothon\db.sqlite3` | যতদিন না **Delete** চাপেন |
| Python প্যাকেজ | `%LOCALAPPDATA%\Kothon\venv` | — |
| ফোল্ডার মোডের Word ফাইল | আপনার অডিও ফোল্ডারের `transcripts` সাব-ফোল্ডার | — |

`%LOCALAPPDATA%` সাধারণত `C:\Users\<আপনার নাম>\AppData\Local`। File Explorer-এর ঠিকানা-বারে `%LOCALAPPDATA%\Kothon` লিখলেই খুলবে।
অন্য কোথাও রাখতে চাইলে `.env`-এ `KOTHON_DATA_DIR=D:\KothonData` লিখে দিন।

> ফোল্ডারের নাম পুরোনো `Kothon` রাখা হয়েছে ইচ্ছে করেই। নাম বদলালে আগের ট্রান্সক্রিপ্ট আর ইনস্টল করা প্যাকেজ হারিয়ে যেত।

⚠️ `.env`-এ API key থাকে। প্রজেক্ট ফোল্ডার কারো সাথে Drive-এ শেয়ার করলে `.env` সাথে চলে যাবে, সে ব্যাপারে সাবধান থাকুন।

## ৬. সমস্যা হলে

| সমস্যা | সমাধান |
|---|---|
| `ffmpeg is not installed` | `winget install Gyan.FFmpeg`, তারপর নতুন উইন্ডো খুলুন |
| `GEMINI_API_KEY is not set` / `API key not valid` | `.env` ফাইলে key ঠিকমতো বসানো আছে কি না দেখুন। স্পেস বা উদ্ধৃতিচিহ্ন থাকবে না। তারপর `start.bat` আবার চালান |
| `429` / quota error | free tier-এর সীমা শেষ। billing চালু করুন বা কিছুক্ষণ পরে **Try again** চাপুন |
| প্যাকেজ আপডেটের পরে চালু হচ্ছে না | `%LOCALAPPDATA%\Kothon\venv` ফোল্ডার মুছে `start.bat` আবার চালান |

টেস্ট চালাতে: `%LOCALAPPDATA%\Kothon\venv\Scripts\activate` তারপর `python -m pytest`

## ৭. পরে ওয়েবসাইট হিসেবে চালাতে চাইলে

কোডে public SaaS-এর সব অংশ আগে থেকেই আছে: signup ও admin approval, credit প্যাক, bKash TrxID যাচাই, pricing/privacy পেজ, Celery worker। লোকাল মোডে এগুলো বন্ধ থাকে।

চালু করতে `.env`-এ `APP_MODE=saas` আর নিচের অংশের সেটিংগুলো পূরণ করুন। তারপর Linux VPS-এ `deploy/` ফোল্ডার থেকে `docker compose up -d --build` চালান। pricing প্ল্যান আর দাম admin প্যানেল (`/admin`) থেকে বদলানো যায়।

---

## ফন্ট

অ্যাপ আর Word ফাইল দুটোতেই বাংলা ফন্ট **Hind Siliguri** (ফ্রি, OFL লাইসেন্স)। প্রথমবার `start.bat` চালালে ফন্টটা আপনার Windows-এ (শুধু আপনার ইউজারের জন্য) ইনস্টল হয়ে যায়, যাতে Word-এও একই ফন্ট দেখায়। Word খোলা থাকলে একবার বন্ধ করে আবার খুলুন। ফন্ট ফাইলগুলো `fonts\` ফোল্ডারে আছে।

## প্রজেক্টের গঠন

```
config/            Django সেটিংস, Celery
accounts/          ইউজার অ্যাকাউন্ট (email লগইন, approval)
billing/           credit, bKash পেমেন্ট (শুধু saas মোডে)
transcription/
  audio.py         ffmpeg: দৈর্ঘ্য মাপা, নীরবতায় কেটে ২০ মিনিটের টুকরো
  gemini.py        Gemini API কল, prompt, JSON schema, retry
  pipeline.py      টুকরো → ট্রান্সক্রিপ্ট → timestamp জোড়া → অনুবাদ
  report.py        Word ফাইল তৈরি
  runner.py        ব্যাকগ্রাউন্ডে job চালানো (লোকাল: thread, সার্ভার: Celery)
  management/commands/transcribe_folder.py
templates/, static/  ওয়েব পেজ
deploy/            Docker + Caddy (পরে publish করার জন্য)
tests/             স্বয়ংক্রিয় টেস্ট
```
