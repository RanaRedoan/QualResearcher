**Download `QualResearcher-Setup-….exe` below**, open it and follow the steps. Already using QualResearcher? Install this over the old version; your transcripts, keys and settings stay as they are. New here? Read the [install guide](https://github.com/RanaRedoan/QualResearcher/blob/main/docs/INSTALL.md).

Windows may say "Windows protected your PC": click **More info → Run anyway**.

### What's new in 1.0.1
- A step-by-step guide in Bangla, inside the app, on how to get a Gemini API key and turn on billing. Open it from the first setup screen ("Gemini API key নেই?"), from Settings, or from **Help: Gemini key** in the left menu.
