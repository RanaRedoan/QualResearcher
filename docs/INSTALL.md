# QualResearcher: ইনস্টল আর ব্যবহারের নিয়ম

এই গাইডটা টিমের সবার জন্য। কোনো প্রোগ্রামিং জানা লাগবে না।

**যা লাগবে:** Windows 10 বা 11 কম্পিউটার, ইন্টারনেট, আর একটা Google অ্যাকাউন্ট (Gemini API key বানানোর জন্য)।

---

## ধাপ ১: ইনস্টলার নামান

1. এই লিংকটা খুলুন: **https://github.com/RanaRedoan/QualResearcher/releases/latest**
2. পেজের নিচের দিকে **Assets** অংশে `QualResearcher-Setup-1.0.0.exe` (সংখ্যাটা আলাদা হতে পারে) ফাইলে ক্লিক করুন।
3. ফাইলটা আপনার Downloads ফোল্ডারে চলে আসবে।

GitHub অ্যাকাউন্ট লাগবে না।

## ধাপ ২: ইনস্টল করুন

1. নামানো `QualResearcher-Setup-….exe` ফাইলে ডাবল-ক্লিক করুন।
2. নীল রঙের **"Windows protected your PC"** বার্তা আসতে পারে। এটা আসে কারণ অ্যাপটা নতুন, Microsoft-এর কাছে এখনো পরিচিত নয়। ভয়ের কিছু নেই:
   - **More info** লেখায় ক্লিক করুন।
   - তারপর **Run anyway** চাপুন।
3. চাইলে **Create a desktop shortcut** টিক দিন, তারপর **Next** → **Install**।
4. শেষে **Open QualResearcher now** টিক দেওয়া থাকলে **Finish** চাপলেই অ্যাপ খুলবে।

Admin password লাগবে না। অ্যাপটা শুধু আপনার Windows অ্যাকাউন্টের জন্য ইনস্টল হয়।

পরে খুলতে চাইলে Start মেনুতে **QualResearcher** খুঁজুন, বা ডেস্কটপের আইকনে ক্লিক করুন।

## ধাপ ৩: Gemini API key দিন (প্রথমবার একবারই)

প্রথমবার অ্যাপ খুললে **Welcome** পেজ আসবে।

1. key না থাকলে পেজের উপরের **"Gemini API key নেই?"** লেখায় ক্লিক করুন। অ্যাপের ভেতরেই ধাপে ধাপে বাংলা গাইড খুলবে (পরে বাম মেনুর **Help: Gemini key** থেকেও পাবেন)। একই গাইড এখানেও আছে: **[Gemini API key বানানোর নিয়ম](GEMINI_API_KEY.md)**।
2. key কপি করে **Gemini API key** ঘরে পেস্ট করুন।
3. **Test key** চাপুন। সবুজ লেখায় "The key works." দেখালে ঠিক আছে।
4. **Name for this key** ঘরে একটা নাম দিন, যেমন যে Gmail দিয়ে key বানিয়েছেন সেটা (`redoan630`)।
5. **Save and continue** চাপুন।

key শুধু আপনার কম্পিউটারেই থাকে, কোথাও পাঠানো হয় না।

## ধাপ ৪: প্রথম ট্রান্সক্রিপ্ট

1. বামে সবুজ **New transcription** বোতাম চাপুন (বা কীবোর্ডে `Ctrl + N`)।
2. অডিও ফাইলটা বক্সে টেনে ছাড়ুন, অথবা বক্সে ক্লিক করে বেছে নিন। MP3, WAV, M4A, OGG, MP4 সব চলে, যত লম্বাই হোক।
3. **Output**: শুধু বাংলা নাকি বাংলা + English, বেছে নিন। শুধু বাংলা দ্রুত হয়, আর ইংরেজি পরেও যোগ করা যায়।
4. একাধিক key থাকলে **Gemini key** থেকে কোনটা দিয়ে করবেন বেছে নিন।
5. **Title** দিন (যেমন `IDI-07 Garment worker, Gazipur`) আর ইন্টারভিউয়ের ধরন বেছে নিন।
6. চাইলে **Respondent profile** খুলে বয়স, এলাকা ইত্যাদি দিন। এগুলো Word ফাইলের উপরে টেবিলে আসবে।
7. consent-এর ঘরে টিক দিয়ে **Start transcription** চাপুন।

এরপর লেখা স্ক্রিনে আস্তে আস্তে আসতে থাকবে। এক ঘণ্টার অডিওতে সাধারণত কয়েক মিনিট লাগে।

**অ্যাপ খোলা রাখুন যতক্ষণ কাজ চলছে।** বন্ধ করে দিলে কাজ থেমে যায়। পরে অ্যাপ খুলে ওই ট্রান্সক্রিপ্টে গিয়ে **Continue from …** চাপলে যেখানে থেমেছিল সেখান থেকে আবার চলবে। কিছুই হারায় না।

## ধাপ ৫: Word ফাইল

ট্রান্সক্রিপ্ট শেষ হলে উপরে তিনটা বোতাম পাবেন:

- **Save as Word**: সাধারণ ট্রান্সক্রিপ্ট, timestamp ছাড়া
- **With timestamps**: প্রতিটা কথার সময়সহ
- **Side by side**: বাংলা আর ইংরেজি পাশাপাশি টেবিলে (ইংরেজি থাকলে)

চাপলে ফাইলটা `Documents\QualResearcher` ফোল্ডারে সেভ হয়ে Word-এ খুলে যাবে। **Show in folder** চাপলে ফোল্ডারটা খুলবে। এই ফোল্ডার বদলাতে চাইলে **Settings → Word files**।

প্রতিটা Word ফাইলের একদম উপরে লাল বক্সে লেখা থাকে যে ট্রান্সক্রিপ্টটা AI-এর সাহায্যে বানানো, তাই হাতে মিলিয়ে দেখতে হবে। অডিও শুনে অবশ্যই মিলিয়ে নেবেন, বিশেষ করে হলুদ দাগ দেওয়া অস্পষ্ট অংশগুলো।

## একাধিক Gemini key

**Settings → Gemini API keys**-এ গিয়ে **Add another key** দিয়ে আরও key যোগ করা যায়, প্রত্যেকটার আলাদা নাম দিয়ে। **Make default** দিয়ে ঠিক করুন সাধারণত কোনটা ব্যবহার হবে। প্রতিটা নতুন ট্রান্সক্রিপ্টে আলাদা key বেছে নেওয়া যায়।

কোনো key-র limit শেষ হয়ে কাজ থেমে গেলে ট্রান্সক্রিপ্টের পেজে **Key:** ঘর থেকে অন্য key বেছে **Continue** চাপুন।

## নতুন ভার্সন এলে

নতুন ভার্সন বের হলে অ্যাপের নিচের সবুজ বারে **"Version … is available — download"** দেখাবে। ক্লিক করে নতুন ইনস্টলার নামিয়ে আগের মতোই ইনস্টল করুন। আপনার ট্রান্সক্রিপ্ট, key আর সেটিংস যেমন ছিল তেমনই থাকবে।

## আনইনস্টল

Windows **Settings → Apps → Installed apps**-এ **QualResearcher** খুঁজে **Uninstall**। ট্রান্সক্রিপ্ট আর সেটিংসও মুছতে চাইলে `%LOCALAPPDATA%\QualResearcher` ফোল্ডারটা হাতে মুছে দিন।
