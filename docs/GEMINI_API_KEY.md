# Gemini API key বানানোর নিয়ম

QualResearcher ট্রান্সক্রিপ্ট বানাতে Google-এর Gemini ব্যবহার করে। এর জন্য প্রত্যেককে নিজের একটা **API key** দিতে হয়। key হলো একটা লম্বা গোপন কোড, যেটা দিয়ে Google বোঝে কাজটা কার অ্যাকাউন্টে হচ্ছে।

সময় লাগবে ৫ মিনিটের মতো। লাগবে একটা Gmail/Google অ্যাকাউন্ট।

---

## ১. key বানান

1. ব্রাউজারে খুলুন: **https://aistudio.google.com/apikey**
2. আপনার Google অ্যাকাউন্ট দিয়ে Sign in করুন।
3. প্রথমবার হলে Google-এর শর্ত মেনে নেওয়ার একটা বার্তা আসবে। পড়ে টিক দিয়ে এগিয়ে যান।
4. **API keys** পেজে একটা key আগে থেকেই থাকতে পারে, কারণ Google নতুন ব্যবহারকারীর জন্য নিজে থেকে একটা বানিয়ে দেয়। না থাকলে **Create API key** চাপুন, আর প্রজেক্ট জিজ্ঞেস করলে যেকোনো একটা বেছে নিন বা নতুন বানান।
5. key-র পাশে **Copy** বোতাম চেপে কপি করুন।

key সাধারণত `AQ.` বা `AIza` দিয়ে শুরু হয়, আর বেশ লম্বা।

## ২. QualResearcher-এ বসান

1. অ্যাপের **Welcome** পেজে (বা পরে **Settings → Gemini API keys → Add another key**) key টা পেস্ট করুন।
2. **Test key** চাপুন। "The key works." দেখালে হয়ে গেল।
3. key-র একটা নাম দিন, যেমন যে Gmail দিয়ে বানিয়েছেন: `redoan630`।

## ৩. Billing চালু করা (আসল ইন্টারভিউয়ের জন্য জরুরি)

key বানানোর পর সেটা **Free tier**-এ থাকে। Free tier-এ দুটো সমস্যা:

- **দিনে অল্প কাজ করা যায়।** এক-দুটো লম্বা অডিওতেই দিনের limit শেষ হয়ে যেতে পারে।
- **গোপনীয়তা:** Free tier-এ যা পাঠানো হয়, Google তা তাদের প্রোডাক্ট উন্নত করতে ব্যবহার করতে পারে। অংশগ্রহণকারীদের অডিওর জন্য এটা গ্রহণযোগ্য নয়। ethics/IRB-এর দিক থেকেও এটা গুরুত্বপূর্ণ।

Billing চালু করলে (Paid tier) limit অনেক বেড়ে যায়, আর Google আপনার পাঠানো ডেটা প্রোডাক্ট উন্নত করতে ব্যবহার করে না।

**কীভাবে:**

1. **https://aistudio.google.com/apikey** পেজে আপনার key-র প্রজেক্টের পাশে **Set up billing** চাপুন।
2. Google Cloud Billing-এর পেজ খুলবে। সেখানে billing account বানান বা আগেরটা বেছে নিন, আর একটা পেমেন্ট মাধ্যম (যেমন ডেবিট/ক্রেডিট কার্ড) যোগ করুন।
3. Google শুরুতে অন্তত **$5** (বা সমপরিমাণ টাকা) আগাম জমা (prepay) নিতে পারে। এটা আপনার ব্যবহারের credit হিসেবে থাকে।
4. কাজ শেষে AI Studio-তে প্রজেক্টের পাশে **Free**-এর বদলে **Tier 1** বা paid লেখা দেখাবে।

**খরচের দিকে নজর রাখা:** AI Studio-র **Dashboard → Usage**-এ দেখা যায় কতটা ব্যবহার হলো। চাইলে Google Cloud-এ **Billing → Budgets & alerts**-এ একটা বাজেট সেট করে রাখুন, তাহলে খরচ সেই সীমায় পৌঁছালে ইমেইল পাবেন।

## key নিরাপদ রাখুন

- key কাউকে দেবেন না, কোথাও পোস্ট করবেন না। যার কাছে key থাকবে, সে আপনার খরচে Gemini চালাতে পারবে।
- টিমের প্রত্যেকে নিজের key ব্যবহার করুন।
- ভুল করে key ফাঁস হয়ে গেলে AI Studio-র **API keys** পেজ থেকে সেটা মুছে (Delete) নতুন key বানান, আর অ্যাপের **Settings**-এ নতুনটা দিন।

## কয়েকটা প্রশ্ন

**একাধিক key রাখা যায়?**
হ্যাঁ। **Settings → Gemini API keys**-এ নাম দিয়ে যত খুশি key রাখা যায়, আর প্রতিটা ট্রান্সক্রিপ্টে কোনটা ব্যবহার হবে বেছে নেওয়া যায়। যেমন আলাদা প্রজেক্টের খরচ আলাদা key-তে রাখতে পারেন। মনে রাখবেন, শুধু free tier-এর limit এড়ানোর জন্য একাধিক অ্যাকাউন্ট ঘুরিয়ে ব্যবহার করা Google-এর শর্তের সাথে নাও মিলতে পারে। নিয়মিত কাজের জন্য billing চালু করাই ঠিক পথ।

**"limit is used up" লেখা আসছে।**
সেই key-র ওই সময়ের limit শেষ। কিছুক্ষণ পর **Continue** চাপুন, বা billing চালু করুন।

**আরও বিস্তারিত:** Google-এর নিজের নির্দেশনা: https://ai.google.dev/gemini-api/docs/api-key আর https://ai.google.dev/gemini-api/docs/billing
