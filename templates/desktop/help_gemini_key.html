Gemini API key কীভাবে পাবেন

{{ SITE_NAME }} ট্রান্সক্রিপ্ট বানাতে Google-এর Gemini ব্যবহার করে। এর জন্য আপনার নিজের একটা API key লাগবে, মানে একটা লম্বা গোপন কোড, যা দেখে Google বোঝে কাজটা কার অ্যাকাউন্টে হচ্ছে। লাগবে একটা Gmail/Google অ্যাকাউন্ট, আর মোটামুটি ৫ মিনিট।

Google AI Studio খুলুন ↗

বোতাম চাপলে আপনার ব্রাউজারে পেজটা খুলবে। এই গাইডটা এখানে খোলা থাকবে, তাই দুটো পাশাপাশি রেখে কাজ করতে পারেন।

  1. Sign in করুন

    যে Google অ্যাকাউন্টে key রাখতে চান, সেটা দিয়ে Sign in করুন। প্রথমবার হলে Google-এর শর্তের একটা বার্তা আসবে। পড়ে টিক দিয়ে Continue চাপুন।

  2. API key তৈরি করুন

    API keys পেজে একটা key আগে থেকেই থাকতে পারে, কারণ নতুন ব্যবহারকারীর জন্য Google নিজেই একটা বানিয়ে দেয়। থাকলে সেটাই ব্যবহার করুন।

    না থাকলে Create API key বোতাম চাপুন। কোন প্রজেক্টে বানাবেন জিজ্ঞেস করলে তালিকা থেকে যেকোনো একটা বেছে নিন, অথবা নতুন একটা বানান।

  3. key কপি করুন

    key-র পাশের Copy বোতাম চাপুন। হাতে সিলেক্ট করে কপি না করাই ভালো, তাতে অনেক সময় key-র শুরু বা শেষ বাদ পড়ে যায়।

    key দেখতে মোটামুটি এরকম: লম্বা, ফাঁকা জায়গা ছাড়া, সাধারণত AQ. বা AIza দিয়ে শুরু।

  4. {{ SITE_NAME }}-এ বসান

    {% if KEY_SET %}Settings → Gemini API keys → Add another key{% else %}key দেওয়ার পেজে{% endif %} ফিরে গিয়ে Gemini API key ঘরে পেস্ট করুন (Ctrl + V)। তারপর Test key চাপুন।

    সবুজ লেখায় “The key works.” দেখালে হয়ে গেল। key-র একটা নাম দিন (যেমন যে Gmail দিয়ে বানিয়েছেন), তারপর Save।

আসল ইন্টারভিউয়ের আগে billing চালু করুন

নতুন key প্রথমে Free tier-এ থাকে। এতে দুটো সমস্যা আছে:

  • দিনে অল্প কাজ করা যায়। এক-দুটো লম্বা অডিওতেই limit শেষ হয়ে যেতে পারে।
  • Free tier-এ যা পাঠানো হয়, Google তা তাদের প্রোডাক্ট উন্নত করতে ব্যবহার করতে পারে। অংশগ্রহণকারীদের অডিওর জন্য এটা ঠিক নয়।

কীভাবে চালু করবেন: AI Studio-র API keys পেজে আপনার প্রজেক্টের পাশে Set up billing চাপুন। একটা billing account বানিয়ে পেমেন্ট মাধ্যম (যেমন কার্ড) যোগ করুন। Google শুরুতে কিছু টাকা (বর্তমানে কমপক্ষে ৫ ডলার) আগাম জমা নেয়, যা পরে ব্যবহারের সাথে কাটা যায়। চালু হলে প্রজেক্টের পাশে Free-এর বদলে paid tier দেখাবে।

খরচ দেখা যায় AI Studio-র Dashboard → Usage-এ। Google Cloud-এর Billing → Budgets & alerts-এ একটা বাজেট ঠিক করে রাখলে খরচ সেই সীমায় পৌঁছালে ইমেইল পাবেন।

key নিরাপদ রাখুন

  • key কাউকে দেবেন না, কোথাও পোস্ট করবেন না। যার কাছে key থাকবে, সে আপনার খরচে Gemini চালাতে পারবে।
  • টিমের প্রত্যেকে নিজের key ব্যবহার করুন।
  • key ফাঁস হয়ে গেলে AI Studio থেকে সেটা Delete করে নতুন key বানান, তারপর এখানে Settings-এ নতুনটা দিন।

সমস্যা হলে

“Google says this key is not valid”
key পুরোটা আসেনি। AI Studio থেকে Copy বোতাম দিয়ে আবার কপি করুন।
“That does not look like a whole Gemini API key”
পেস্ট করার সময় ফাঁকা জায়গা বা অর্ধেক key চলে এসেছে। ঘর খালি করে আবার পেস্ট করুন।
“The key works, but its limit is used up for now”
key ঠিক আছে, শুধু ওই সময়ের limit শেষ। পরে আবার চেষ্টা করুন, অথবা billing চালু করুন।
“Could not reach Google”
ইন্টারনেট সংযোগ দেখে আবার চেষ্টা করুন।
