**Download `QualResearcher-Setup-….exe` below**, open it and follow the steps. New here? Read the [install guide](https://github.com/RanaRedoan/QualResearcher/blob/main/docs/INSTALL.md) and [how to get a Gemini API key](https://github.com/RanaRedoan/QualResearcher/blob/main/docs/GEMINI_API_KEY.md).

Windows may say "Windows protected your PC" the first time: click **More info → Run anyway**.

### In this version
- Desktop app for Windows: its own window, no browser and no login.
- First-run setup for your Gemini API key, with a Test button.
- Several named Gemini keys; choose one for each recording, or switch and continue a stopped one.
- Live transcript while it is written; continue a stopped job from where it stopped.
- Save as Word (clean, with timestamps, or Bangla and English side by side), opened straight in Word. Each file starts with a red reminder that it was made with AI help and must be checked.
- Hind Siliguri font installed for Word automatically.
- "New version available" notice in the status bar.
